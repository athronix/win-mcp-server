# CL-003 — win-system（Windows 系统操作）

> 版本 v0.3.0 · 2026-11-26 · 合并版 DDD 记录（Phase 1/2/4 要点）

## 1. 范围

在底座与 PS 桥之上实现第一个业务 server：系统信息、服务、进程、事件日志、任务计划、注册表、启动项、网络。

**不在范围**：账户管理、磁盘/分区、防火墙、电源控制（需更谨慎的权限与回滚设计，留后续 CL）。

## 2. 方案

### 2.1 桥的模块调用协议（新增 `op=module`）

```json
{"id":"req_1","op":"module","params":{"module":"system","function":"Get-ServiceList","args":{"Filter":"spool"}}}
```

- **白名单双层**：`module` 必须在 `ModuleWhitelist` 中，`function` 必须在该模块的函数列表里；否则 `UNKNOWN_MODULE` / `FUNCTION_NOT_ALLOWED`
- **脚本作用域 dot-source**：模块加载必须在主循环（脚本作用域）执行；在函数内 dot-source 会导致模块函数随函数返回而消失（实测踩坑）
- 模块返回 `[ordered]` 字典，桥统一 `ConvertTo-Json -Depth 8 -Compress`
- 列表类结果统一 `{ items, count }`，避免单元素退化为对象

### 2.2 PowerShell 模块 `packages/core/ps/modules/system.ps1`

| 函数 | 说明 |
|---|---|
| `Get-SystemOverview` | CIM 查询 OS/CPU/内存/提权状态（约 2-4s） |
| `Get-ServiceList` | 服务名/显示名/状态/启动类型，支持过滤 |
| `Invoke-ServiceAction` | start/stop/restart，操作后回读状态 |
| `Get-ProcessList` | 按 CPU 时间倒序，含 PID/内存/线程/路径 |
| `Stop-ProcessItem` | 按 PID 或名称结束，支持 force |
| `Get-EventLogEntries` | `Get-WinEvent` + 级别映射，消息截断 400 字符 |
| `Get-ScheduledTaskList` | 任务 + 上次/下次运行时间 |
| `Get-RegistryValue` | 单值或列全部值（含类型） |
| `Set-RegistryValue` | **写前自动备份**到 `%LOCALAPPDATA%\win-mcp\backups\reg-*.json`，写后回读校验 |
| `Get-StartupItems` | HKCU/HKLM Run + 启动文件夹 |
| `Get-NetworkConfig` | 适配器/IPv4/网关/DNS |

### 2.4 运行时

`packages/servers/src/shared/runner.ts` 统一：启动桥 → 注册能力 → 组装 `ToolGate`（策略/审批/审计共享单实例）→ stdio 或 `WIN_MCP_HTTP_PORT` 指定的 HTTP + `/health`。

> **ADR-011**：6 个 server 物理上放在同一个 `@win-mcp/servers` 包内，各自独立 `bin` 入口（`win-mcp-system` 等）。理由是共享构建配置与依赖，运行形态仍是 6 个独立进程；若后续需要独立 npm 包再拆分。

## 4. 实现中修正的缺陷

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | `system.ps1` 加载即语法错误（"缺少右大括号"） | **PowerShell 的 hashtable 字面量里不能直接写 `try/catch`**（它是语句不是表达式） | 5 处 `= try {...} catch {...}` 改为先算变量 |
| 2 | 模块加载成功但调用报"术语不被识别" | **在函数内 dot-source，函数定义只落在该函数作用域** | 改为主循环（脚本作用域）dot-source |

## 5. 遗留

| 项 | 说明 |
|---|---|
| 系统信息耗时 2-4s | CIM 查询慢；已设 `timeoutMs=20000`，可用 `systeminfo` 替代优化 |
| 注册表 HKLM 写默认禁用 | 需在部署配置里把 `HKLM:\SOFTWARE\**` 加入 `registryWriteAllowlist`，属显式决策 |
| 事件日志消息为系统语言 | 中文系统返回中文；上层不得匹配文案，只依赖 `eventId`/`level` |
| 未实现账户/磁盘/防火墙/电源 | 风险更高，留 CL-003b |
